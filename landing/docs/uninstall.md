# Uninstall

1. If a broker account is connected, **flatten** or close positions you don't want left alone, then **Pause**.
2. Optional: on [your account](/account/), **Remove** this computer so the licence is free for another one.
3. Remove everything Savant keeps: **Settings → Data → Reset** (deletes the `.savant` folder: settings, journal, keys).
4. Remove the app:
   - **macOS**: quit Savant from the tray, then drag Savant from Applications to the Trash.
   - **Windows**: Settings → Apps → Installed apps → Savant → Uninstall.
   - **Linux**: delete the AppImage, or `sudo apt remove savant` / `sudo dnf remove savant`.

Uninstalling doesn't cancel your subscription: do that on [your account](/account/).
