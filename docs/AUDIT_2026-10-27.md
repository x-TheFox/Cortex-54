# Pre-launch audit ledger (2026-10-27)

The operator supplied a pre-launch audit of the repository. Every finding below was re-checked against the code before
anything changed; the audit is a list of claims, not a verdict. **Verdict** is ours: *Confirmed* (fixed), *Partly*
(the residual truth fixed), *Rejected* (wrong, with the reason) or *Operator* (a decision or an account step only the
operator can take). Decisions: ADR-085…090.
